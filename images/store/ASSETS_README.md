# Noverse Store — recursos visuales

Coloca los recursos en `images/store/`.

- `Banner_PulsarRm_png` — banner, recomendado 1600 × 900 px.
- `Icon_PulsarRm_png` — icono, 512 × 512 px.
- `Screenshot1_PulsarRm_png`, `Screenshot2_PulsarRm_png`, `Screenshot3_PulsarRm_png` — capturas, 1080 × 1920 px.
- `Video_PulsarRm` — presentación, 1920 × 1080 px.

Para AstralWorld usa `Banner_AstralWorld_png`, `Icon_AstralWorld_png` y `Video_AstralWorld`. Se aceptan extensiones .webp, .png, .jpg, .jpeg, .avif; para video .mp4, .webm y .mov.
